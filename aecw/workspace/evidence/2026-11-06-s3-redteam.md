## 1. 本阶段做了什么

| 动作 | 实现 |
|---|---|
| 进程间锁 | `aecw/.aecw-lock` 用 `open(..., 'wx')` 排他创建；重试退避；60s 超时；120s 陈旧锁清理 |
| 读-改-写原子化 | `fact` / `dissent` / `change` / `resolve` / `accept` / `log` 全程持锁；读、ID 分配、写都在锁内 |
| 退出兜底 | `process.on('exit')` 释放持有的锁；`fail()`/异常/正常退出都不会留下锁 |
| 未完成事务恢复 | `withLock` 获取锁后先 `recoverTxn`；恢复上一次未提交的 journal 回滚，再执行当前命令 |
| 唯一 ID | `nextIdInTable` 在锁内扫描对应表，32 路并发不重号 |
| 写入原子性 | 单文件 temp + rename；多文件 backup + journal + 回滚（S1 已建，S3 加锁） |
