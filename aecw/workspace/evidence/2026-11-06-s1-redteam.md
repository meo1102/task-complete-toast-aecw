## 1. 本阶段做了什么

### P0-1 · 停止把 check 绿灯当治理可靠

| 动作 | 实现 | 位置 |
|---|---|---|
| check 声明边界 | 开头与结尾都打印“结构/一致性检查；不是授权/发布证明” | `aecw/bin/aecw.mjs` `cmdCheck` |
| 开放 S1/S2 改为 FAIL | 表格解析 + 大小写不敏感（`open/OPEN/Open`），逐条列出 DR ID；exit 1 | `openHighRows` |
| gate 拒绝通过类决策 | `通过/有条件通过` 需：开放 S1/S2 = 0 + 成功 verify attestation + 人类签署（`--signed-by` = owner） | `cmdGate`、`readAttestation` |
| gate 不再受自由文本放行 | 默认决策改为 `退回补证`；未知决策拒绝；attestation 校验 kind/ok/open_s1s2/tree_hash/项目/过期 | `normalizeGateDecision` |
| gate 历史不可覆盖 | 同名同日门禁已存在即拒绝（仅显式 `--force` 可用于 demo/迁移） | `cmdGate` |
| init 生成完整状态 | 生成 `PROJECT.json`、`state.json`、`criteria.md`、全部文档状态头；`init → check` 为 0/0 | `cmdInit` |
| 生成器自洽 | gate/freeze/start/inbox/CR 生成内容都带状态头；模板同步加头 | `core/*.template.md` |

### P0-7 · Markdown / ID 类型安全

| 动作 | 实现 |
|---|---|
| 表格字段转义 | `cleanCell`：CR/LF/控制字符→空格，反斜杠与竖线转义；claim/evidence/statement/title/reason/impact/by 等全部走它 |
| 只操作正确表 | `resolve` 只接受 `DR-xxx` 且只查 A 表；`change --id` 只接受 `CR-xxx` 且只查 C 表；跨类型拒绝 |
| ID 分表分配 | `nextIdInTable` 只扫对应 section 的 ID 列；自由文本里的 `F-999` 不再把下一条事实推成 `F-1000` |
| gate 名称白名单 | 1–60 字符；拒绝控制字符、换行、竖线、路径分隔符、`*?"<>` 与前导点/空白 |
| 多文件半事务 | `commitFiles`：备份 + journal + 原子 rename；任一写失败回滚全部目标，保留明确失败；下次命令可恢复未完成 journal |
| 单文件原子写 | ledger/acceptance/decisions 全部 `writeFileAtomic`（temp + rename） |
| 人类身份最小绑定 | S1/S2 `resolve`、`accept`、charter/blueprint 裁决、`start` 必须 `--by` = `state.owner`；`accept` 接受/有条件接受必须有证据 |
| charter 不得自批准 | `change --type charter/blueprint --decision 接受` 在提出命令里直接拒绝，只能单独 `--id` 由人类裁决 |
| 重复裁决拒绝 | 已 closed 的 DR、已裁决的 CR 再次裁决即拒绝 |
