## 2. P0-3 · 阶段状态机与冻结 payload

- 合法状态：`seed → frozen → executing → closed`；`paused` 只能从 `executing` 进入，`resume` 回 `executing`；`closed` 为终态。
- `freeze`：只在 `seed` 或 `closed` 时允许；`closed` 阶段必须换新 stage id；写 direction/blueprint/criteria/product 的 canonical hash 与 `payload_hash`，嵌入 `<!-- AECW-FREEZE ... -->`。
- `start`：只从 `frozen`；读取该 stage 的冻结节，校验 payload hash 自洽，再重算 direction/blueprint/criteria/product，逐项比对；任一字节变化即拒绝。
- 门禁文件名包含时间戳/随机 ID，不覆盖历史；`gate`/`freeze`/`start` 均拒绝同名覆盖。
- `pause` / `resume` / `close`：只允许合法迁移；`close` 需人类 + 已存在的阶段门禁，且门禁决策与 `--decision` 一致。
- `state.json` 与 `STATUS` 同步更新（含 AECW-STATE 摘要），`check` 继续对账。
